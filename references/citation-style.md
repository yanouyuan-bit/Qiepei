# 出处著录格式

脚注体，依中文人文社科期刊与学位论文通行体例。用户思路单里若另有版本约定或刊物要求，以用户为准。下表中的作者、题目、页码只示意格式，不是真实出处。

## 一、脚注：首次出现

| 类型 | 格式 | 例 |
|---|---|---|
| 古籍点校本 | 作者〔撰／注〕：《书名》卷X《篇名》，地点：出版社，年份，第X页。 | 司马迁：《史记》卷四十七《孔子世家》，北京：中华书局，1959年，第X页。 |
| 古籍见于今人集注本 | 作者：《书名》，见某某《某书》，地点：出版社，年份，第X页。 | 《论语·为政》，见朱熹《四书章句集注》，北京：中华书局，1983年，第X页。 |
| 古籍影印本 | 编者：《书名》卷X，影印本说明，第X页。 | 某某编：《某书》卷一〇九，某楼影印明刻本，第X页。 |
| 四库本 | 作者：《书名》卷X，文渊阁《四库全书》第X册，第X页。 | 某某：《某集》卷二十五《某序》，文渊阁《四库全书》第X册，第X页。 |
| 全集本 | 作者：《书名》，《全集名》第X册，地点：出版社，年份，第X页。 | 鲁迅：《呐喊》，《鲁迅全集》第1册，北京：人民文学出版社，2005年，第X页。 |
| 语录体 | 编者：《书名》卷X·篇名，点校者，地点：出版社，年份，第X页。 | 某某编：《某语录》卷一·某篇，某某点校，地点：出版社，年份，第X页。 |
| 近现代专著 | 作者：《书名》，地点：出版社，年份，第X页。 | 费孝通：《乡土中国》，北京：北京大学出版社，2012年，第X页。 |
| 中译本 | 作者：《书名》，译者，地点：出版社，年份，第X页。 | 韦伯：《新教伦理与资本主义精神》，阎克文译，上海：上海人民出版社，2010年，第X页。 |
| 大陆期刊 | 作者：《题目》，《刊名》年份第X期，第X页。 | 某某：《题目》，《社会学研究》2020年第3期，第X页。 |
| 台港期刊 | 作者：《题目》，《刊名》第X卷第X期，年份，页X—X。 | 某某：《题目》，《某刊》第31卷第10期，2004年，页X—X。 |
| 西方古典 | 作者：《书名》卷章，Bekker／Stephanus 码。 | 亚里士多德：《政治学》I.2，1253a1—3。／柏拉图：《理想国》IV，435b—c。 |
| 西方近代原典 | 作者：《书名》卷节。 | 霍布斯：《利维坦》I, xiii。 |
| 转引 | 原作者语，转引自某某《某书》，地点：出版社，年份，第X页。 | 某某语，转引自某某《某研究》，地点：出版社，年份，第X页。 |

## 二、脚注：再次出现

| 情形 | 写法 |
|---|---|
| 紧接上一注，同一书 | 同上书，第X页。 |
| 紧接上一注，同一书同一页 | 同上。 |
| 隔了别的书 | 简式：《史记》卷四十七，第X页。／某某前引文，第X页。／朱熹《四书章句集注》，第X页。 |
| 同一作者多种著作 | 简式带书名，不用「前引书」 |

「同上书」的"上"指紧邻的上一条脚注。中间隔了任何别的文献都不能用。

## 三、脚注里的附加交代

放在页码之后，句号隔开：

- 系年：系于某公某年"某事"。
- 释篇：释某篇。
- 注家：某某注："……"
- 异读：影印本此句无标点，亦可读作"……"；本文从点校本。
- 真伪：今本与某书所引非同一书，说见某某，第X页。
- 年代限定：某注家晚于原书数百年，此系后世自觉化。

## 四、文末参考文献

分三类，各类内按作者时代或姓氏排。不出页码（期刊出起讫页）。

**古籍**
- 司马迁：《史记》，北京：中华书局，1959年。
- 朱熹：《四书章句集注》，北京：中华书局，1983年。

**近现代原著**
- 费孝通：《乡土中国》，北京：北京大学出版社，2012年。
- 韦伯：《新教伦理与资本主义精神》，阎克文译，上海：上海人民出版社，2010年。

**今人论著**
- 某某：《题目》，《社会学研究》2020年第3期，第X—X页。
- 某某：《题目》，《某刊》第31卷第10期，2004年，页X—X。

## 五、标点与数字

- 书名号《》，篇名也用《》，书名内再有书名用〈〉：《〈史记〉研究》。
- 卷次用汉字：卷四十七、卷一〇九。册数、页码、年份、期数用阿拉伯数字。
- 页码范围用一字线「—」：第132—140页。
- 汇编里页码前后留空格（第 135 页）便于阅读；骨架脚注里不留（第135页），依用户正文习惯。
- 出版年后加「年」；版次写在年份后：2011年第2版。
