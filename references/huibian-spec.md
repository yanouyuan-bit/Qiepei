# 引用汇编规范

阶段 2 读。汇编是切配的主产品：全章要用的引文，每条带原文与完整出处，可以径直落成脚注。

## 一、文件结构

```
# 第N章 引用汇编

> 一句话交代：供哪一章写作时取用；覆盖哪些文献（按出场顺序）；繁简处理说明。

**版本约定**
- 逐书列出所用版本（从思路单抄来，切配核对后补全）

---

## 一、〔文献甲〕          ← 按文献分章，顺序依思路单出场顺序
以下各条依〔版本〕。      ← 章首交代本章所依版本，章内出处只写页码
### 1　〔模块或主题〕      ← 章内按思路单模块分节
> 引文
——第 X 页。
**（便签）**
...
## 二、〔文献乙〕
...
## N-4、当代研究者的可引论断   ← 今人论著里可借力或须回应的判断，单独归一章
## N-3、页码待核              ← 定位不了的条目，带定位记录
## N-2、未收                  ← 考虑过但不收的，写明原因
## N-1、按模块的调用索引      ← 每个模块用哪些条、在哪页
## N、文末参考文献            ← 古籍 / 近现代原著 / 今人论著
```

## 二、单条格式

```
> 为政以德，譬如北辰，居其所而众星共之。

——《为政》，第 X 页。
**（模块A 承重句。）**
```

四要素：

| 要素 | 规则 |
|---|---|
| 原文 | 引用块。照录规则见 reading-guide 第三节 |
| 出处 | 「——」起头。本章已交代版本的，只写页码；跨版本、转引、另书的写全。释某篇、系于某事等背景放出处行括号内 |
| 归属 | 通过所在小节体现；一条兼属多模块时在便签里写「兼供模块C」 |
| 便签 | 加粗括号，可无。规则见 SKILL.md 第四节：只指不论，切配自拟的加「切配建议：」 |

出处行示例：

```
——第 80 页。（释某卦）
——《某史》卷十《某志》，第 1091 页。（系于某年某事。）
——《某书》，转引自某某《某研究》，第 153 页。
——某某按语，同上书，第 154 页。
——某某《题目》，《某刊》2020 年第 6 期，第 132 页注。
——某某《某书》卷六。【只注卷次·待核页码】
```

## 三、分章分节的原则

- **按文献分章**，不按模块分章。厨师写作时是按模块取料，但核对时是按书翻，汇编按书排，索引按模块排，两头都照顾到。
- 同一作者多种著作放同一章，章内先按书再按模块。
- 章内小节标题用思路单的模块名或主题名，不自造名目。
- 反例、反面材料单独立节，标题写明「反面材料」或「预答」，便签指出它是哪个论点会遇到的反例。
- 「今本真伪」「版本疑难」这类落笔前必须交代的事单独立节，收今人论著里的相关判断。

## 四、末尾四部分

### 页码待核

每条：原文（可简）＋现有出处信息＋定位记录（带日期）。定位记录写查过什么、卡在哪、回哪里补。这一部分是给厨师的作业单。

### 未收

考虑过、切过、最后不收的条目，一句话一条，写明原因：

- 其义由某条承担（写出哪条）
- 无版本／无来源
- 思路单已定为分析性对照，不出引文
- 只作检索线索

厨师看到未收清单，才知道切配没有漏看。

### 按模块的调用索引

按思路单的模块顺序，每个模块下列出用到的条目：文献＋页码，一行一书。索引里的页码必须与正文条目一致。

```
**模块A　为政者的位置**
- 《论语·为政》第 X、X 页；《荀子·王制》第 X 页
- 反面材料三条：第 X—X 页
- 今人论断：某某第 X 页；断句异读预答：某某第 X 页注
```

### 文末参考文献

分三类：古籍、近现代原著、今人论著。格式见 citation-style.md。只列汇编里实际出现的文献。

## 五、缺口

汇编做完，对照思路单逐模块检查：思路单说要什么，汇编里有没有。没有的写进交付说明的「缺口清单」：模块名、要什么、查过哪些文献没找到。**不用记忆里的材料填缺口。**

## 六、体量

一章的汇编通常几十到一百多条。条目宁多勿少，但每条都要过三条铁律。取舍是厨师的事，切配把能用的都摆出来，用便签帮厨师认路。

## 七、增量更新

厨师写作中会回来要补料。补料时：

- 新条目追加到对应文献章的对应小节，不重排已有编号。
- 已有条目页码修正后，同步改调用索引。
- 页码待核里解决了的条目，移回正文并删掉定位记录，或在记录后追加「已核（日期）」。
- 文件头加一行「更新记录」：日期＋改了什么。
