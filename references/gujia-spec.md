# 材料骨架规范

阶段 3 读。骨架是案板：汇编里的材料按思路单的上锅顺序排成一篇带脚注的正文，引文之间只有连接句，没有一个字是炒过的。厨师拿到骨架，在引文之间填入自己的解读与论证，就成初稿。

## 一、文件结构

一节一个文件，`第N章_第M节_材料.md`。

```
# 一、〔节标题〕                    ← 从思路单来

〔路线图段：一到三句，交代本节看几样东西、按什么顺序〕

## （一）〔小节标题〕

〔定位句〕

> 引文[^1]

[^1]: 完整出处。

〔定位句／引导句〕

> 引文[^2]

[^2]: 同上书，第 X 页。

...
```

脚注定义紧跟在引文段之后，不集中放文末。这样厨师改一段时出处就在眼前。

## 二、连接句：只准四类

| 类 | 作用 | 允许说什么 | 例 |
|---|---|---|---|
| 路线图句 | 节首、小节首 | 本节／本小节看什么，先后顺序（内容来自思路单） | 本节先从《论语》看……，再从《孟子》看……，然后看……，最后摆出…… |
| 定位句 | 引文之前 | 下一条是什么书、什么位置、什么形式 | 《论语·为政》篇首有一句总纲，用的是一个比喻：／同篇另有一条，前半句与后半句对举：／《尽心下》有一个三分句： |
| 引导句 | 引文之前 | 谁说的、说的是什么对象 | 某某概括这一层的要义：／某某指出，／某某早就指出此书借经义讲别的事： |
| 交代句 | 任意位置 | 版本、真伪、年代、转引、与前章的呼应、材料分组的先后 | 第一章第二节曾述及……／此注家晚于原书数百年，这些材料严格说是……／《孟子》中另有一条把治人者与治于人者分作两类。 |

每两条引文之间的连接文字一到两句。超过两句，多半已经在炒。

### 定位句可以描述形式，不可以描述意义

看得见的形式可以说：句式一致、前半句讲什么后半句讲什么、中间用哪个字相连、分几层、共几条、几处重复。例：

> 这几条的句式高度一致，前半句讲为政的方式，后半句讲民的反应，中间用一个"则"字相连。

看不见的意义不能说：这句话表明、意味着、揭示了、其实是在说。

### 命题用语只能从思路单来

思路单里的术语（例如模块名、厨师给某种关系起的名目）可以在路线图句和定位句里用，因为那是厨师自己的话。切配不自造术语，不引入思路单没有的概念。

## 三、禁用词表

连接句里出现下列词，几乎必然是在炒，一律不用：

因此、所以、由此可见、可见、这说明、这表明、这意味着、意味着、揭示、反映、体现、正是、恰恰、恰好、不难看出、显然、值得注意的是、实际上、本质上、归根结底、换言之、也就是说、从根本上、无非是、不过是、决定了（作论断用时）、构成了（作论断用时）、说明了、证明了、印证了、支撑了。

评价性形容词也不用：深刻、精辟、重要、关键、核心、根本、有力、典型、经典。

若实在需要提示厨师某条材料的分量，用便签，不用连接句：

```
> 引文[^7]

[^7]: 出处。
**（切配便签：此条为模块A 承重句。）**
```

骨架里的便签交稿前由厨师删除，所以要用统一前缀「切配便签：」便于全文检索。

## 四、脚注

- 全文脚注从 1 顺序编号，按出现顺序，不跳号。
- 一书首次出现写全：作者、题目、卷次、地点、出版社、年份、页码。再次出现用「同上书，第 X 页」（紧接上一注且同书）或简式「《史记》卷四十七，第 X 页」（隔了别的书）。
- 「同上书」只能紧接同一书的上一条脚注，中间隔了别的书就用简式。
- 版本疑难、真伪、断句异读放在首次出现那条脚注里交代。
- 「系于某年某事」「释某篇」「某某注」这类背景放脚注里，不放正文。
- 转引：「转引自某某《某书》，第 X 页」。
- 详细著录格式见 citation-style.md。

## 五、排列

- 顺序完全按思路单。思路单没定先后的，按汇编内顺序，并在交付说明里指出「此处先后未定」。
- 反面材料按思路单要求的位置放。思路单说「先摆出再化解」，骨架就把反例引文放在正面材料之后，加一句交代句引出，不加化解——化解是厨师的活。
- 对照项（西典、镜像项）放在思路单指定的位置，交代句只说「第几章曾述及」或「某某在某书里说」。
- 一段里连续多条同类短引（如同一篇里的数条短语），合并成一个引用块，每行一条，各自带脚注号。

## 六、骨架里不能有的东西

- 段首段尾的总结句、过渡句（"综上""由此我们看到""这就把问题引向了"）。
- 对引文的复述、改写、白话翻译。
- 对两条引文之间关系的判断（"与此相反""与之呼应""更进一步"）。要提示关系，用便签。
- 任何思路单里没有的论点、概念、分类。
- 任何没有在汇编里出现、没有文件与页码支撑的引文。

## 七、自检

交付前跑 `scripts/check_footnotes.py 骨架.md 汇编.md`，确认：

1. 每个 `[^n]` 有定义、每个定义被引用。
2. 编号按出现顺序连续。
3. 每条引文能在汇编里找到（脚本按去标点后的文本匹配，报未匹配的条目）。
4. 连接句里没有禁用词（脚本报出现位置）。
5. 「同上书」不出现在第 1 条脚注，且紧接同书。

脚本报出来的问题逐条处理或在交付说明里解释。
