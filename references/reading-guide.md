# 读料规范

阶段 1、2 开始前读。目标只有一个：切出来的每一条引文，厨师拿着文件都能翻到。

## 一、先认文件

| 类型 | 判断 | 处理 |
|---|---|---|
| 文字版 PDF | 能直接抽出文本 | 直接读；页码看页面上印刷的页码 |
| 扫描版 PDF | 抽不出文本或全是乱码 | 先 OCR（pdf skill / tesseract），标「经 OCR 核对」；生僻字、异体字逐个对照页面图像 |
| OCR 文本、Markdown、Word | 用户已转好 | 直接读；若无页码信息，标「无印刷页码」 |
| 网络文本、数据库导出 | 无版本信息 | 只能作检索线索，不进汇编正文；进「待核」 |

每份文献先记下：作者、题目、卷次、出版社、年份、版次。封面页、版权页、目录页都要翻。认不出就写「版本待补」，不要凭书名推测版本。

## 二、页码：印刷页码，不是 PDF 页序

- 引文页码一律取**页面上印刷的页码**。PDF 阅读器显示的第几页只是文件页序，与印刷页码常常差着扉页、目录、序言的页数。
- 如果文件没有印刷页码（如某些数据库导出的期刊全文、扫描件裁掉了页脚），写 `【PDF页N·待核】`，让厨师回原书补。
- 引文跨页：写「第 12—13 页」。跨页处如有分行、断词，照原文续接，不加字。
- 古籍影印本：记卷次＋叶次（如「卷一〇九，第 6 页」或「第 3 册，第 412 页」），依用户版本约定。
- 期刊：记年份、期数、页码；台港刊物常写「页 X—X」，依刊物习惯。
- 西方古典：依 Bekker／Stephanus 码（如 1253a1—3、435b—c），不出中译本页码；正文直引中译时另注中译本。

页码定不下来，写一条带日期的「页码定位记录」，说明查过什么、卡在哪里、回哪本书哪一卷去补：

```
**（页码定位记录 2026-01-01：材料来源某文引此条只注"《某书》卷六"，不出页码。所用点校本卷六在第 443—447 页，此条在该卷后半，当在第 445 页前后，须回原书核。）**
```

## 三、原文照录

- 一字不改。错字、异体、缺笔照录，必要时在便签里注「原文如此」。
- 繁体转简体。专名、异体字、通假字仍其旧（「羣」不改「群」，「乡」不改「向」）。
- 引号：汇编里保留原书引号形态，古籍用「」；骨架里按用户正文习惯统一（通常是中文双引号）。
- 删节只用「……」。**只在同页同段内删节。** 不同页、不同段的句子即使意思连贯也要拆成两条分别录、分别标页。
- 标点：从所用版本的标点。同一句有异读（如影印本无标点、点校本断句不同），在便签或脚注里交代「本文从某本」。
- 原书夹注、小字、按语与正文分开：正文录进引文，按语另作一条并标明「某某按语」。
- 引文里出现的经典原文（如引经文），不拆出来另立条目，除非思路单要。

## 四、转引

- 从 B 书里看到 A 书的话，只能录作「转引自 B」，不能写成直接引 A。
- 用户版本约定若写「古典皆回原书，不走转引」，那么转引条目照录，但标 `【回原书·待核页码】`，进「待核」清单。
- 今人论著引古籍而只注卷次不注页码的，如实记「只注卷次」，并在页码定位记录里写清。

## 五、切多长、切哪句

- 切**承重句**：思路单里某个模块要靠它站住的那句。承重句前后的语境句可以一并录成长条，便签里指出承重句是哪一句。
- 一条引文通常在 150 字以内。长段落分两种切法：长条（保语境）＋短条（承重句），两条都录，便签互指。
- 同一句话在几处出现（如总论与分论重复），各录各的页，便签注明「与第 X 页同」。
- 不切的：与任何模块无关的句子；意思由已收条目承担的重复句（写进「未收」，注明由哪条承担）。

## 六、读今人论著时

今人论著（期刊论文、专著）切两类东西：

1. **可引论断**：作者自己下的、思路单里某模块可以借力或必须回应的判断。录原句，标页。
2. **材料线索**：作者引的古籍原文及其出处。这类只作线索，能回原书的回原书，回不了的按转引处理。

不切的：作者的论证过程、综述、背景介绍。那是厨师自己的活。

## 七、不做的事

- 不凭记忆补引文。哪怕是「天行健，君子以自强不息」，也要在用户给的版本里翻到再录。
- 不猜页码，不猜版本，不猜作者原意。
- 不在读料时"顺手"写解读。读到觉得重要的地方，只在便签里"指"一下。
