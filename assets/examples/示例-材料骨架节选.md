# 示例：材料骨架节选

*与上一示例配套的虚构骨架。页码为占位。注意引文之间只有路线图句、定位句、引导句、交代句，没有一句解读。*

# 一、为政者与民

本节先从《论语》看为政者被安放的位置，再从《孟子》看民被安放的位置，然后看《荀子》的舟水之喻，最后摆出《孟子》里的一条反面材料。

## （一）为政者的位置

《论语·为政》篇首有一句总纲，用的是一个比喻：

> 为政以德，譬如北辰，居其所而众星共之。[^1]

[^1]: 朱熹：《四书章句集注》，北京：中华书局，1983年，第X页。

同篇另有一条，前半句与后半句对举：

> 道之以政，齐之以刑，民免而无耻；道之以德，齐之以礼，有耻且格。[^2]

[^2]: 同上书，第X页。

《荀子·王制》以舟水为喻：

> 君者，舟也；庶人者，水也。水则载舟，水则覆舟。[^3]

[^3]: 王先谦：《荀子集解》，北京：中华书局，1988年，第X页。

## （二）民的位置

《孟子·尽心下》有一个三分句：

> 民为贵，社稷次之，君为轻。[^4]

[^4]: 朱熹《四书章句集注》，第X页。

《离娄上》讲得天下与得民、得心的次第：

> 得天下有道：得其民，斯得天下矣。得其民有道：得其心，斯得民矣。[^5]

[^5]: 同上书，第X页。

某某概括这一层的要义：

> 〔今人论断原文〕[^6]

[^6]: 某某《题目》，《某刊》2020年第X期，第X页。
**（切配便签：此条为模块B 承重句。交稿前删。）**

《孟子》中另有一条把治人者与治于人者分作两类：

> 劳心者治人，劳力者治于人；治于人者食人，治人者食于人。[^7]

[^7]: 朱熹《四书章句集注》，第X页。

**这一段骨架里，每处连接文字属于哪一类：**

| 文字 | 类 |
|---|---|
| 本节先从……最后摆出…… | 路线图句（内容来自思路单） |
| 《论语·为政》篇首有一句总纲，用的是一个比喻： | 定位句（位置＋形式） |
| 同篇另有一条，前半句与后半句对举： | 定位句（描述形式，不描述意义） |
| 《荀子·王制》以舟水为喻： | 定位句 |
| 某某概括这一层的要义： | 引导句 |
| 《孟子》中另有一条把治人者与治于人者分作两类： | 交代句引出反面材料，不化解 |

厨师拿到这份骨架之后，在北辰之喻后写为政者为什么"居其所"，在"民为贵"后写贵的是什么，在"劳心者"之后写这条为什么不构成反例。那些都是炒，切配一个字不碰。
